`main.py` writes two lines to `/output/entry.txt`:

```
A toaster is like a tiny sun that lives in a box on your kitchen counter and tans your bread until it turns golden.
The analogy works because both give off heat and change colour, but it leaves out that the sun never pops up with a ding when it is done.
```

Run it with:

```sh
python3 main.py
```
